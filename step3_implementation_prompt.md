# Шаг 3: Детальный промпт для реализации приложения

## 1. Общая задача

Создать интерактивное веб-приложение на Python с использованием Streamlit и Plotly для бэктестинга стратегии ребалансировки портфеля. Приложение должно позволять пользователю выбирать активы, веса, период, частоту ребалансировки, сравнивать результат с Buy & Hold и отображать ключевые метрики и графики.

## 2. Технологический стек и Зависимости

*   **Язык:** Python 3.9+
*   **Веб-фреймворк:** Streamlit
*   **Визуализация:** Plotly
*   **Обработка данных:** Pandas, Numpy
*   **Источник данных:** yfinance

Создать файл `requirements.txt` со следующим содержимым (можно использовать последние стабильные версии):

```txt
streamlit
plotly
pandas
numpy
yfinance
```

## 3. Архитектура

Реализовать приложение в трех файлах:

1.  **`app.py`:** Основной файл приложения Streamlit. Отвечает за пользовательский интерфейс (UI), сбор ввода, вызов функций из `core.py` и `plots.py`, отображение результатов.
2.  **`core.py`:** Содержит основную логику бэктестинга и расчета метрик. Должен включать функции для загрузки данных, выполнения расчетов ребалансировки и B&H, расчета метрик. **Критически важно:** использовать декораторы Streamlit (`@st.cache_data`) для кэширования ресурсоемких функций.
3.  **`plots.py`:** Содержит функции для создания интерактивных графиков с использованием Plotly.

## 4. Детализация реализации

### 4.1. Файл `core.py`

*   **Импорты:** `pandas`, `numpy`, `yfinance`, `datetime`, `streamlit as st` (только для декораторов).
*   **Функции:** Добавить type hints и docstrings для нетривиальных функций.

    *   **`@st.cache_data`
        `def load_price_data(tickers: list[str], start_date: datetime.date, end_date: datetime.date) -> pd.DataFrame | None:`**
        *   Принимает список тикеров, начальную и конечную даты.
        *   Использует `yfinance.download()` для загрузки цен закрытия (`'Close'`).
        *   Обрабатывает ошибки `yfinance` (например, неверный тикер, нет данных): если загрузка не удалась хотя бы для одного тикера, или результат пустой, вернуть `None`. Логировать ошибку (можно через `print` или `st.error` если будет вызвано из `app.py` - но лучше вернуть `None` и обработать в `app.py`).
        *   Удаляет строки с `NaN` (`dropna()`).
        *   Добавляет столбец `'Cash'` со значением `1.0`.
        *   Возвращает DataFrame с ценами или `None` при ошибке.

    *   **`@st.cache_data`
        `def run_backtest(price_data: pd.DataFrame, target_weights: dict[str, float], rebalance_freq: str, initial_capital: float) -> pd.DataFrame:`**
        *   Принимает DataFrame цен (выход `load_price_data`), словарь целевых весов (включая 'Cash'), строку с частотой ребалансировки (Pandas Offset Alias, например 'M', 'Q', 'A'), начальный капитал.
        *   **Реализация ребалансировки:**
            *   Определить фактические даты ребалансировки на основе `rebalance_freq` и индекса `price_data`.
            *   Создать DataFrame для хранения ежедневного состояния портфеля (колонки: `Holdings` (dict), `Cash`, `Asset_Values` (dict), `Total_Value`, колонки для стоимости каждого тикера).
            *   Инициализировать начальное состояние (весь капитал в 'Cash').
            *   Цикл по дням: перенос состояния, обновление стоимости активов, пересчет `Total_Value`.
            *   В дни ребалансировки (и в первый день): рассчитать новые количества активов (`Holdings`) и `Cash` на основе `target_weights` и *текущей* `Total_Value`. Обновить `Total_Value` и стоимости тикеров после ребалансировки.
            *   Сохранить итоговую `Total_Value` ребалансируемого портфеля в колонку (например, `'Rebalanced_Value'`).
        *   **Реализация Buy & Hold:**
            *   Рассчитать начальное распределение капитала согласно `target_weights` на первый день.
            *   Рассчитать количество акций каждого тикера (кроме 'Cash'), купленных на старте.
            *   Рассчитать стоимость портфеля B&H на каждый день, сохраняя количество акций неизменным (стоимость 'Cash' компонента остается постоянной).
            *   Сохранить итоговую `Total_Value` портфеля B&H в колонку (например, `'BH_Value'`).
        *   Возвращает DataFrame с колонками как минимум: `'Rebalanced_Value'`, `'BH_Value'` (индекс - даты).
        *   Обеспечить обработку возможных ошибок (например, деление на ноль, если цена актива 0).

    *   **`@st.cache_data`
        `def calculate_metrics(backtest_results: pd.DataFrame, risk_free_rate_annual: float) -> dict[str, dict[str, float]]:`**
        *   Принимает DataFrame с результатами (`'Rebalanced_Value'`, `'BH_Value'`), годовую безрисковую ставку (в виде десятичной дроби, например, 0.035).
        *   Рассчитывает метрики для *обоих* портфелей ('Rebalanced', 'Buy & Hold'), используя формулы из `step0_project_plan.md`:
            *   Начальная стоимость (из `backtest_results`).
            *   Конечная стоимость.
            *   CAGR (Compound Annual Growth Rate).
            *   Максимальная просадка (Max Drawdown) (в %). **Важно:** использовать цены, а не доходности для расчета пиков и просадок.
            *   Дневные доходности (простые или логарифмические - выбрать один подход, например, простые: `pct_change()`).
            *   Аннуализированная волатильность (на основе дневных доходностей, `* np.sqrt(252)`).
            *   Коэффициент Шарпа (аннуализированный).
            *   Коэффициент Сортино (аннуализированный, использовать безрисковую ставку как Target Return Rate). Рассчитать downside deviation.
            *   Фактор восстановления (Total Profit / Abs Max Drawdown in currency).
        *   Обработать возможные ошибки (например, нулевая волатильность -> Sharpe = NaN или 0).
        *   Возвращает словарь словарей, например: `{'Rebalanced': {'CAGR': 0.1, ...}, 'Buy & Hold': {'CAGR': 0.08, ...}}`.

### 4.2. Файл `plots.py`

*   **Импорты:** `plotly.graph_objects as go`, `pandas as pd`.
*   **Функции:** Добавить type hints.

    *   **`def plot_normalized_prices(price_data: pd.DataFrame) -> go.Figure:`**
        *   Принимает DataFrame с ценами (выход `load_price_data`, без 'Cash').
        *   Нормализует цены: первая цена каждого актива = 100 (`df / df.iloc[0] * 100`).
        *   Создает фигуру `go.Figure`.
        *   Добавляет линии (`go.Scatter`) для каждого тикера.
        *   Настраивает layout: заголовок ('Normalized Asset Prices'), оси.
        *   **Важно:** Убедиться, что легенда интерактивна (по умолчанию в Plotly) для включения/отключения линий.
        *   Возвращает объект `go.Figure`.

    *   **`def plot_equity_curves(backtest_results: pd.DataFrame) -> go.Figure:`**
        *   Принимает DataFrame с результатами (`'Rebalanced_Value'`, `'BH_Value'`).
        *   Создает фигуру `go.Figure`.
        *   Добавляет линии (`go.Scatter`) для 'Rebalanced Portfolio' (`'Rebalanced_Value'`) и 'Buy & Hold Portfolio' (`'BH_Value'`).
        *   Настраивает layout: заголовок ('Portfolio Equity Curve'), оси.
        *   **Важно:** Установить логарифмическую шкалу для оси Y (`fig.update_yaxes(type='log')`).
        *   Возвращает объект `go.Figure`.
